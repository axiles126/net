# PATCH — мережева лабораторія

Тренажер комп'ютерних мереж, який рахує за справжніми правилами: маска й найдовший префікс,
шлюз за замовчуванням, TTL, NAT і CGNAT, IPv6 (вмикається окремо), Wi-Fi із зоною покриття,
репітер і DHCP. Вбудований репетитор розбирає вашу схему й пояснює, що саме зламано.
Помилка в налаштуванні ламає зв'язок так само, як зламала б удома — і трасування показує, де саме.

Працює повністю офлайн. Жодних зовнішніх запитів, жодної аналітики, жодного сервера:
схема зберігається тільки у вашому браузері (localStorage) і нікуди не надсилається.

## Як викласти на GitHub Pages

1. Створіть репозиторій, наприклад `netlab`.
2. Завантажте в його корінь усі файли з цієї теки:
   `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`,
   `icon-maskable-512.png`, `apple-touch-icon.png`.
3. Settings → Pages → Source: `Deploy from a branch`, гілка `main`, тека `/ (root)`. Save.
4. За хвилину сторінка буде на `https://ВАШ_НІК.github.io/netlab/`.

HTTPS у GitHub Pages увімкнено за замовчуванням — це обов'язкова умова для service worker.

## Як встановити на телефон

**Android / Chrome:** відкрийте сторінку → у застосунку з'явиться кнопка «встановити»
у шапці, або меню браузера (⋮) → «Встановити застосунок».

**iPhone / Safari:** кнопка «Поділитися» → «На екран «Домів»». На iOS кнопки «встановити»
не буде — Apple не підтримує це запрошення, лише ручний спосіб.

Після встановлення застосунок запускається без адресного рядка й працює без інтернету.

## Оновлення

Змінили `index.html` — відкрийте `sw.js` і підніміть версію:

```js
const VERSION = 'patch-v2';
```

Без цього телефон продовжить показувати стару версію з кешу.

## Репетитор

Вкладка «Репетитор» працює повністю офлайн: вона перевіряє конфігурацію тими самими правилами,
за якими рухається пакет, і показує таблицю «хто кого бачить» зі справжніми пінгами.
Ключі й інтернет для цього не потрібні, дані нікуди не надсилаються.

За бажанням там же можна підключити живу модель своїм ключем API — для вільних питань.
Ключ зберігається лише у вашому браузері. На спільному пристрої цього робити не варто,
і робочий чи чужий ключ туди вставляти не можна.

## Дані

Схема зберігається автоматично після кожної зміни. Видалити все:
вкладка «Завдання» → «стерти збережене».
